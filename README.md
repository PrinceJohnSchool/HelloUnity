# Hello Unity — GPE104 Project 1

A minimal Unity 6000.6.0f1 project: one sphere in the scene with a custom
C# component (HelloWorld.cs) that prints "Hello World" to the Console when
the game starts.

- Milestone 1 (Hello Unity): the project + component.
- Milestone 2 (Hello Source Control): this repo — Unity .gitignore, a
  development branch merged into main, verbose commit messages.

In Unity: open the project, run **Hello Unity > Build Scene**, press Play.
